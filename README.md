# LangGraph Hello World

A minimal multi-tool agent demonstrating LangChain, LangGraph, LangSmith, and DSPy with Ollama.

## Project Overview

This demo explores the modern LLM application stack through 5 progressive approaches:

| Approach | Tool | Purpose |
|----------|------|---------|
| 1. Basic Agent | LangChain + LangGraph | Build a working agent |
| 2. Tracing | LangSmith | Visualize agent reasoning |
| 3. Testing | Pytest | Assert correctness |
| 4. Evaluation | LangSmith + LLM-as-Judge | Systematic quality measurement |
| 5. Optimization | DSPy | Auto-tune prompts |

---

## Setup Guide

### Prerequisites

1. **Ollama** (required)
   ```bash
   # Install Ollama
   curl -fsSL https://ollama.com/install.sh | sh
   
   # Pull required models
   ollama pull llama3.2          # For basic agent (2GB)
   ollama pull llama3.2:1b     # For DSPy optimization demo (1.3GB)
   ```

2. **LangSmith** (optional - for evaluation/tracing)
   - Sign up at https://smith.langchain.com
   - Create API key in Settings
   - Add to `.env`: `LANGSMITH_API_KEY=your_key`

3. **Python dependencies**
   ```bash
   # Install uv (if needed)
   brew install uv
   
   # Create venv and install deps
   make install
   ```

### Verify Setup

```bash
# Terminal 1: Start Ollama
make ollama

# Terminal 2: Run basic agent
make run-basic
```

## Approaches

This demo implements 5 approaches to building and improving LLM applications. Start with Approach 1, then explore others.

### Approach 1: Basic Agent (LangChain + LangGraph)

Build a working multi-tool agent with LangGraph's ReAct prompting.

**Run:**
```bash
make run-basic
```

**Files:** `main.py`, `tools.py`

**What it does:**
- Agent decides which tool to call based on user input
- Uses ReAct (Reasoning + Acting) prompting strategy
- Tools: calculator, wikipedia_search, get_current_time

---

### Approach 2: LangSmith Tracing

Visualize the agent's reasoning step-by-step.

**Setup:**
```bash
# Add to .env
LANGSMITH_API_KEY=your_key
```

**Run:**
```bash
make run-tracing
# Ask questions, then view traces at https://smith.langchain.com
```

**What you see:**
- Each tool call and its arguments
- Intermediate reasoning steps
- Latency and token usage

---

### Approach 3: Pytest Testing

Write assertions to verify agent correctness.

**Run:**
```bash
make pytest
```

**Files:** `tests/test_agent.py`

**Test types:**
- **Golden tests**: Verify output matches expected answer
- **Trajectory tests**: Verify correct tool was called

**Example:**
```python
def test_calculator_add(self, agent, config):
    result = agent.invoke({"messages": [("user", "What is 5 + 7?")]})
    assert "12" in result["messages"][-1].content
```

---

### Approach 4: LLM-as-Judge Evaluation

Compare agent outputs against golden answers using an LLM judge.

**Setup:**
```bash
# Upload golden dataset to LangSmith
make upload
```

**Run:**
```bash
make run-evaluation
```

**What it does:**
1. Loads golden examples from LangSmith
2. Runs agent on each input
3. Uses LLM to judge if output matches golden
4. Logs results to LangSmith experiments

**View results:** https://smith.langchain.com/evaluation/experiments

---

### Approach 5: DSPy Optimization

Automatically optimize prompts using MIPROv2 teleprompter.

**Run:**
```bash
make dspy
```

**Files:** `scripts/dspy_example.py`

**What it does:**
1. Loads golden examples from LangSmith
2. Runs baseline agent
3. Compiles with MIPROv2 (optimizes instructions + few-shot examples)
4. Saves optimized prompt to `optimized_agent.json`

**Key DSPy concepts:**
- **Signature**: Defines inputs/outputs (not the prompt itself)
- **Module**: Wraps signature with prompting strategy
- **Teleprompter**: Algorithm that optimizes the prompt
- **Metric**: Function measuring correctness against golden

## Learning Path

For understanding the ecosystem:

1. **Start here**: Run `make run-basic` to understand the basic agent
2. **Add tracing**: Run `make run-tracing` to see inside the agent
3. **Write tests**: Run `make pytest` to see assertion-based testing
4. **Try evaluation**: Run `make run-evaluation` to see systematic measurement
5. **Explore DSPy**: Run `make dspy` to see prompt optimization

Each approach builds on the previous - you can use them together in production.
